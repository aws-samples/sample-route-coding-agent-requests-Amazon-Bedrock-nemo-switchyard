# Troubleshooting

| Symptom                                                               | What to check                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plugin import fails                                                   | Use the image built from `docker/gateway/Dockerfile`. The stock LiteLLM image doesn't contain the plugin.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Configuration is rejected                                             | Run `npm run validate:profile -- stage`. Routed candidates share the `switchyard` group. Stage requires two distinct candidates, capable first; Random requires at least two.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Requests select an unexpected tier                                    | Check declaration order, `picker`, and the conversation history. Include tool results in every Stage request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Random configuration fails                                            | Match weights to unique candidates in YAML order. Use finite, nonnegative weights with at least one positive value.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `Routed model ... has no baseline group`                              | Add a one-model group for that model with the same `litellm_params.model`, named by its alias, for example `nemotron-super-3-120b`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `Baseline group ... has N deployments`                                | Only `switchyard` may list more than one deployment. Give each baseline group exactly one model, or move the extra deployment into `switchyard`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `... must use the Bedrock Converse API`                               | Prefix every model with `bedrock/converse/`, for example `bedrock/converse/nvidia.nemotron-super-3-120b`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `router_settings.plugins must be exactly [...]`                       | Set `router_settings.plugins` to only `switchyard_gateway.configured.ROUTING_PLUGIN`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `litellm_settings.callbacks must register ...`                        | Add `switchyard_gateway.configured.ROUTING_PLUGIN` to `litellm_settings.callbacks` so request changes apply.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `litellm_settings.callbacks must not register ...`                    | Remove `switchyard_litellm.configuration.configured_plugin.ROUTING_PLUGIN`; the gateway wrapper replaces it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `... allow_client_side_credentials must be absent or false`           | Remove `allow_client_side_credentials` from `general_settings` and `litellm_settings`. It turns off LiteLLM's request-body guard, which rejects fields such as `api_base` and `aws_role_name`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `... must not set litellm_params.configurable_clientside_auth_params` | Remove `configurable_clientside_auth_params` from that deployment. It lets a request body override the deployment's credentials or endpoint for that model group.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| HTTP 400 `Rejected Request: <field> is not accepted`                  | The request body carried `api_key`, `aws_access_key_id`, `aws_secret_access_key`, `aws_session_token`, or an `Authorization` entry in `extra_headers`, `headers`, or `provider_specific_header` (as a mapping or a list of pairs), anywhere in the body: the message names the path, for example `extra_body.api_key` or `fallbacks[0].switchyard[0].api_key`. Content fields (`messages`, `tools`, `functions`, `tool_choice`, `response_format`) are not inspected. The gateway signs every Bedrock call with its task role and refuses caller credentials, because LiteLLM would keep a body `api_key` and reuse it for other callers' requests, and would send a caller's `Authorization` header instead of the task role's signature. Remove the field; the master key goes in the `Authorization` request header only. |
| `... config ... is missing or not readable by uid 10001`              | The container runs as uid 10001. For Compose, check that `profiles/$ROUTING_PROFILE/` exists and its files are world-readable. For ECS, the task writes the configuration from its environment, so redeploy the stack.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `npm run test:proxy`: proxy did not become healthy                    | LiteLLM can take more than a minute to start on a loaded host. Set `E2E_READY_TIMEOUT` (seconds, default 180), and read the container log printed with the failure.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `npm run test:proxy`: set `E2E_PROVIDER_HOST`                         | Rootless Docker, or a Linux bridge without an IPv4 gateway, gives no address the test can detect. Set `E2E_PROVIDER_HOST` to a host IP address the container can reach.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| HTTP 401                                                              | Retrieve the generated master key from the correct stack and Region. The complete key begins with `sk-`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| HTTP 400 with type `no_db_connection`                                 | The key begins with `sk-` but isn't the master key. The gateway runs LiteLLM without a database, so LiteLLM can't look up other keys and returns this error instead of 401. The request is still refused. Retrieve the generated master key from the correct stack and Region.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| HTTP 404 with body `Not found`                                        | The path isn't on the load balancer allowlist. Only `/v1/chat/completions`, `/v1/models`, and `/health/liveliness` are forwarded, so the Responses and Messages APIs and `models.retrieve` (`/v1/models/{id}`) get this 404. To forward another path, test it against the local container first, add it to `ALLOWED_PATHS` in `lib/gateway-service.ts`, update the stack test, and redeploy.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Smoke test: closed-path check skipped or failing locally              | The closed-path check runs only for non-local hostnames; it skips `localhost`, `127.0.0.1`, `::1`, and `host.docker.internal`, which have no load balancer. For any other local address, such as a LAN IP, the check runs against LiteLLM directly and fails on a path LiteLLM serves; that failure means no load balancer is in front, not a stack problem. Use `GATEWAY_URL=http://127.0.0.1:4000` for local runs.                                                                                                                                                                                                                                                                                                                                                                                                         |
| Missing model or access denied                                        | Run preflight for the selected profile. Verify the model ID, API support, inference profile, account access, and Region.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Route 53 context lookup fails                                         | Confirm AWS credentials and the account/Region resolved by CDK. Supply the AWS CLI credentials profile consistently with `--profile` when needed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `cdk destroy` reports `allowedCidr is required`                       | `ALLOWED_CIDR` is unset or empty. For cleanup, pass `-c allowedCidr=203.0.113.0/24 -c allowPlainHttp=true` directly. This satisfies local validation without changing the deployed allowlist.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Synth reports `No HTTPS settings were given`                          | Pass `-c domainName=<host>` with `-c hostedZone=<zone>` or `-c certificateArn=<arn>`. A stack deployed over HTTP before HTTPS became the default needs `-c allowPlainHttp=true` on its next deploy.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Gateway is unreachable                                                | Check the allowed CIDR against your current public IP, ALB target health, and ECS logs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Curl appears to hang                                                  | Use `--connect-timeout` and `--max-time`. Inspect ECS logs for provider timeouts or throttling.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Selected model is unclear                                             | Read `x-litellm-model-name`; the response body's `model` is the public group.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Cost is unavailable                                                   | The runner needs a known concrete model and complete uncached token usage. Missing prices or usage are not treated as zero cost.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

Use CloudWatch's LiteLLM log group for container startup and request errors. The local equivalent is `docker compose logs litellm`.
